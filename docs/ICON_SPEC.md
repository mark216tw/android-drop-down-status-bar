# App 圖示設計規格

## 視覺方向

- 風格：活潑、友善、年輕化
- 造型：粗線條卡通工具圖示
- 主題：通知面板搭配向下箭頭，直接表達「下拉通知欄」功能
- 友善元素：箭頭加入簡化笑臉
- 主色：紫藍、薄荷綠、珊瑚粉、亮黃
- 外框：深藍灰粗外框，確保小尺寸仍清楚可辨識

## Adaptive Icon 尺寸

| 項目 | 尺寸 | 畫布座標 |
|---|---:|---:|
| 最終前景與背景圖層 | `108×108 dp` | `0–108` |
| 外框裁切區 | `72×72 dp` | `18–90` |
| 核心安全區 | `66×66 dp` | `21–87` |
| 核心圖案 | `59.4×59.4 dp` | `24.3–83.7` |

核心圖案尺寸為安全區的 90%：

```text
66 dp × 90% = 59.4 dp
```

核心圖案在 `108×108 dp` 畫布中水平及垂直置中，四周各保留 `24.3 dp`。

## 圖層

### 背景層

檔案：`app/src/main/res/drawable/ic_launcher_background.xml`

- 完整填滿 `108×108 dp` 畫布。
- 紫藍底色搭配薄荷綠、珊瑚粉及亮黃幾何色塊。
- 允許 Android Launcher 依圓形、圓角方形或其他遮罩裁切。

### 前景層

檔案：`app/src/main/res/drawable/ic_launcher_foreground.xml`

- 核心圖案嚴格限制於 `24.3–83.7 dp`。
- 使用約 `5 dp` 視覺粗外框。
- 通知面板、狀態列及向下箭頭在小尺寸下仍能辨識。

### 單色層

檔案：`app/src/main/res/drawable/ic_launcher_monochrome.xml`

- 供 Android 13 以上主題圖示使用。
- 保留通知面板外框及向下箭頭輪廓。

## 驗收條件

- 前景及背景向量畫布皆為 `108×108 dp`。
- 核心圖案不超出 `66×66 dp` 安全區。
- 核心圖案寬高均為安全區的約 90%。
- 圓形、圓角方形及方形 Launcher 遮罩下均保留主要圖案。
- Android 13 以上主題圖示具有獨立單色版本。
