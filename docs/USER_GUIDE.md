# 使用指南

## 第一次啟用

1. 開啟「下拉通知欄」。
2. 點擊「啟用無障礙服務」。
3. 閱讀權限用途說明後，點擊「繼續」。
4. 在 Android 無障礙設定中找到「下拉通知欄」。
5. 開啟服務並確認系統提示。
6. 返回 App，確認狀態顯示為「服務已啟用」。
7. 使用「測試通知欄」或「測試快速設定」確認功能。

## 點擊 App 圖示

服務啟用後，點擊桌面的 App 圖示會立即執行預設動作，不會停留在設定頁。

預設動作可設定為：

- 開啟通知欄
- 開啟快速設定

如需重新進入設定頁，長按 App 圖示並選擇「設定」。

## 加入桌面小工具

1. 長按桌面空白處。
2. 選擇「小工具」。
3. 找到「下拉通知欄」。
4. 加入「通知欄」或「快速設定」小工具。
5. 小工具應占用 `1×1` 桌面格數。

如果從舊版更新後仍顯示為 `1×2`，請移除舊小工具並重新加入。Launcher 會保存既有小工具的格數，App 無法強制修改已加入的小工具尺寸。

## 震動回饋

「成功執行後震動」預設開啟。關閉後不會影響通知欄或快速設定功能。

## 停用服務

1. 長按 App 圖示並選擇「設定」。
2. 點擊「管理無障礙服務」。
3. 在 Android 設定中關閉「下拉通知欄」。

停用後，App 圖示及小工具不會再執行系統全域動作。

## 疑難排解

### 點擊後沒有反應

- 確認無障礙服務仍為啟用狀態。
- 關閉並重新啟用服務。
- 檢查手機的省電或背景執行限制。
- 部分鎖定畫面、工作設定檔或企業管理裝置可能禁止展開系統面板。

### 點擊 App 圖示出現設定頁

服務未啟用或系統尚未完成服務連線時，App 會開啟設定頁並顯示提示。啟用服務後再試一次。

### 無法安裝 APK

- 確認 Android 版本為 8.0 以上。
- 允許瀏覽器或檔案管理員安裝未知應用程式。
- Debug Key 可能與先前安裝版本的簽章不同，必要時先移除舊版再安裝。
