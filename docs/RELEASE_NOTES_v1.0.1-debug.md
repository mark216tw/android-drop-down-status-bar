# 下拉通知欄 v1.0.1 Debug

> 此版本是 **Debug 測試版本**，已設定為 GitHub Pre-release，不是正式發行版。

## 功能

- 點擊 App 圖示一鍵展開通知欄或快速設定。
- 提供通知欄及快速設定兩種 `1×1` 桌面小工具。
- 提供完整無障礙服務啟用引導及權限用途說明。
- 可選擇 App 圖示的預設動作。
- 可開啟或關閉成功操作後的震動回饋。
- 長按 App 圖示可開啟設定。
- 支援繁體中文、英文及系統深色模式。

## 本次更新

- App 名稱統一為「下拉通知欄」。
- 重新設計活潑、友善、年輕化的粗線條卡通 App 圖示。
- 圖示使用 `108×108 dp` Adaptive Icon 前景與背景雙層資源。
- 核心圖案占 `66×66 dp` 安全區的 90%。
- 新增 Android 13 以上單色主題圖示。
